
# K-pop Concerts
This project was created to display K-pop concert information and allow users to search, filter, and sort concerts easily.
## Features
- View concert information
- Search by artist or city
- Filter concerts by type
- Sort concerts by date, price, or artist
- About page
- Login page
- Register page

 npm install

2- Run the project : 
 npm run dev
