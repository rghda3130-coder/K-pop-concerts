## Project Summary

K-Pop Concerts is a web application for browsing K-pop concerts. Visitors
can search, filter, and sort concerts. The main resource is the concert
(artist, tour, type, city, venue, date, price, description).

**Current status:** Milestone 1 (React SPA with local mock data) is
complete. Milestone 2 (Express API, MongoDB, authentication, and
owner-only editing) is in progress.

## Main Features

Implemented (Milestone 1):

- Search by artist or city, filter by type, and sort (combined)
- Responsive layout for desktop and mobile
- Home, About, Login, and Register pages (Login and Register are
  non-functional placeholders)

Planned (Milestone 2):

- User registration, login, and logout (session cookies)
- Create, update, and delete concerts (owner only)

## Technologies

- React
- Vite and React Router
- Planned: Node.js, Express, MongoDB, Mongoose
- Render (deployment)

## Local Setup

### Client

Open the client folder.
Install dependencies with npm install.
Copy the required environment-variable names from .env.example into a local .env file.
Run the client with npm run dev.

### Server

Open the server folder.
Install dependencies with npm install.
Create a local .env file using .env.example.
Run the server with npm run dev or the script defined by the group.
